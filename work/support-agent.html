Customer Support Agent

A support assistant for a fictional online store. It helps with order tracking, cancellations and returns, answers policy questions from the store's documentation, and hands complex cases to a person.

Role
Backend developer
Team
Solo
Status
Live
Links
Live demo ↗ · Code ↗

Overview

  • Customers chat with the assistant about their orders. It can look orders up and act on them through a fixed set of tools.
  • Questions about the store's policies are answered from its documentation, and cases it shouldn't handle alone are escalated to a human.

What I built

  • A FastAPI backend where the assistant, using the OpenAI API, works through typed tools instead of accessing the database directly.
  • Refund rules kept in code rather than left to the model.
  • RAG over the store's policy documents with ChromaDB, order data in SQLite, and a Docker setup for deployment.
